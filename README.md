# 📌 Mi Proyecto ECOMMERCE By José Espinoza

Aquí encontrarás información sobre como se trabajó el proyecto. 

## 🚀 Características
- Catalogo de productos consumidos desde una API.
- Se listaron los productos con una tarjeta por cada uno.
- Diseño de tarjetas fue copiado de una plantilla. 
- Se utilizó @media para que el sitio se adapte a las dimenciones de distintos dispositivos.
- Se utilizo Flex para ordenar y listar los productos
- Se utilizó interface de modelo para hacer mas accesible el uso de la API.
